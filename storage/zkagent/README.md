# 存储证明节点

## 模块概述
存储证明节点负责响应区块链上分配的存储挑战任务，生成零知识证明并提交链上验证结果。

---

## 核心功能
1. **挑战任务监听**
   - 定期轮询链上分配的挑战；
   - 确定当前节点负责的分片任务。

2. **分片下载与验证**
   - 通过 IPFS 获取对应分片；
   - 校验分片哈希一致性。

3. **零知识证明生成**
   - 构造零知识证明 π；
   - 支持 SNARK/STARK 可扩展证明结构。

4. **链上结果提交**
   - 调用多链 SDK 提交证明结果；
   - 验证回执并记录日志。
