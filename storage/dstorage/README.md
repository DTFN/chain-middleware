# 存储代理节点（Storage Agent Node）

## 模块概述
存储代理节点是系统的核心接入层，负责与用户进行交互，并调度文件存储、元数据上链、零知识挑战生成等功能。

---

## 核心功能
1. **文件上传与分片处理**
   - 接收用户文件；
   - 使用 **ISA-L** 进行纠删码编码；
   - 生成数据块与冗余块。

2. **分布式存储管理**
   - 将分片分布式上传至多个 IPFS 节点；
   - 支持分片追踪与恢复。

3. **区块链交互**
   - 调用五条主流链的 SDK，提交元数据（哈希、分片索引、权限等）；
   - 记录文件上链状态与交易哈希。

4. **零知识挑战机制**
   - 针对每个分片生成挑战任务；
   - 验证来自存储证明节点的证明响应；
   - 将验证结果同步上链。

## 源码构建
### 1. 构建程序 dstorage 
```bash
# 进入源码目录
cd dstorage

# 创建构建目录
mkdir build

# 进入构建目录
cd build

# 构建配置
cmake ../ -DCMAKE_BUILD_TYPE=Release

# 编译代码
make -j8

# 安装程序
make install
```
