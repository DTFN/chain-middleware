# 去中心化存储系统（基于零知识证明）

## 🌐 项目简介
本系统是一套 **基于零知识证明机制的去中心化存储系统**，旨在实现可信数据的安全存储与完整性验证。  
系统整体架构由以下核心组成部分构成：
- **存储代理节点（Storage Agent Node）**
- **存储证明节点（Storage Proof Node）**
- **分布式 IPFS 存储集群**
- **区块链层（多链接入）**

系统支持包括：
- **零数链**
- **长安链（ChainMaker）**
- **FISCO BCOS**
- **Fabric**
- **以太坊（Ethereum）**
等五条主流区块链平台的 SDK 接入。

---

## 系统架构概述
1. 文件提交与元数据上链

用户向存储代理节点提交文件。
存储代理节点对文件进行纠删码编码，将数据分片并上传至IPFS网络，获取每个分片的唯一标识（CID）。
存储代理节点将文件元数据（如CID列表、存储节点信息等）提交至区块链上的智能合约，完成存证。

2. 存储证明节点注册与数据同步
存储证明节点向存储代理节点注册，声明其参与文件存储与证明。

3. 挑战与证明生成
智能合约定期或随机发起存储挑战，指定某个存储证明节点提交存储证明。
被挑战的存储证明节点根据其对应的IPFS存储的分片数据，生成零知识证明，证明其确实持有数据且未篡改，而无需泄露数据内容。
该证明被提交至智能合约。

4. 存储验证与数据恢复
智能合约自动验证提交的零知识证明的有效性。
验证结果被记录在链上。
存储代理节点可查询验证结果，确保整个存储网络的健康状态，当数据异常时，触发数据恢复逻辑。



核心角色说明

用户：文件所有者，发起存储请求。
存储代理节点：协调者，处理文件编码、分发、元数据上链与挑战发起。
IPFS节点：提供分布式存储基础设施，存储纠删码分片。
存储证明节点：访问IPFS节点获取数据并响应挑战，生成存储证明。
智能合约：自治程序，管理元数据、发起挑战、验证证明。
区块链：提供不可篡改的账本，记录所有交易与验证结果。
